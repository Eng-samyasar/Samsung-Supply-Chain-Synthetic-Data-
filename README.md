## 📊 Supply Chain Data Analysis Project

This project focuses on analyzing supply chain data to gain insights into sales, inventory, suppliers, customers, and shipping performance.

The workflow started with Python for data exploration, cleaning, and preprocessing. After preparing the data, it was directly loaded into a database for structured storage.

Using SQL, a consolidated view was created to organize the most important fields and simplify data access for analysis.

Finally, Power BI was used to design a star schema data model and build an interactive dashboard that highlights key KPIs, performance trends, and operational insights to support data-driven decision-making.

> ⚠️ **Disclaimer:** The dataset used in this project is synthetic/educational and does not represent real or official data of any company, including Samsung.

## 📊 مشروع تحليل بيانات سلسلة التوريد

يركز هذا المشروع على تحليل بيانات سلسلة التوريد بهدف استخراج رؤى تساعد في فهم أداء المبيعات، المخزون، الموردين، العملاء، وعمليات الشحن.

بدأ العمل باستخدام بايثون لإجراء عمليات استكشاف البيانات وتنظيفها ومعالجتها، ثم تم تحميل البيانات مباشرة إلى قاعدة بيانات لتنظيمها بشكل منظم.

بعد ذلك، تم استخدام SQL لإنشاء View تحتوي على أهم الأعمدة لتسهيل الوصول إلى البيانات وتحليلها.

وأخيرًا، تم استخدام Power BI لبناء نموذج بيانات بنظام Star Schema وتصميم داشبورد تفاعلي يعرض أهم المؤشرات (KPIs) والاتجاهات، مما يساعد في اتخاذ قرارات مبنية على البيانات.

> ⚠️ **تنويه:** البيانات المستخدمة في هذا المشروع هي بيانات افتراضية/تعليمية، ولا تمثل بيانات حقيقية أو رسمية لأي شركة، بما في ذلك شركة Samsung.
